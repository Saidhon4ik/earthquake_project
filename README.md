# Earthquake Project

An end-to-end data engineering project built with Microsoft Fabric.

## Architecture

- **Bronze:** Ingest and store raw earthquake data from the USGS API in the Lakehouse.
- **Silver:** Clean, standardize, and transform the raw data using PySpark notebooks.
- **Gold:** Prepare curated data for analytical use.

## Tools

- Microsoft Fabric Lakehouse
- Fabric Notebooks and PySpark
- Data Factory
- GitHub for version control
